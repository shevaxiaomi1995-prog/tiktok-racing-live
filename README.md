# TikTok Racing LIVE

Стартовый проект интерактивных 3D-гонок для показа в TikTok LIVE Studio как источник браузера.

## Что уже заложено в прототип

- 3D-арена на Three.js с овальной трассой и машинками.
- Зритель присоединяется командой `Старт`, `start` или `!join`.
- Таймер регистрации на 3 минуты запускается только после набора минимального количества участников (по умолчанию 10).
- Максимум — 50 машин. Когда лимит достигнут, новые заявки не принимаются.
- Гонка длится 5 минут. Машины едут автоматически; победитель определяется по пройденной дистанции к моменту окончания таймера.
- После гонки все участники выходят, затем начинается новый набор.
- Таблица победителей хранит число побед и участий; она сохраняется в браузере и может быть сброшена вручную.
- В панели ведущего настраиваются лимиты, таймеры, порог лайков и правила подарков.
- Лайки суммируются отдельно для каждого зрителя: каждый набранный порог выдаёт ускорение.
- Для каждого подарка можно задать эффект, длительность и силу. Доступны ускорение, щит, замедление лидера, сдвиг назад и оглушение.
- Включены тестовые кнопки, чтобы проверить механику без TikTok.
- Есть Node.js/Express + WebSocket сервер-приёмник нормализованных событий.

## Локальный запуск

1. Установи Node.js 20 или новее.
2. Скопируй `.env.example` в `.env`.
3. В терминале в папке проекта выполни `npm install`.
4. Запусти `npm run dev`.
5. Открой `http://localhost:5173`.
6. В панели ведущего используй тестовые кнопки «Старт», «+100 лайков», отправку подарка и пакость лидеру.

Тестовые кнопки только имитируют события и не отправляют реальные сообщения или подарки в TikTok.

## Приём событий

Отправляй нормализованные JSON-события на `POST /api/events` с заголовком `Authorization: Bearer YOUR_EVENT_INGEST_TOKEN`. Формат событий и примеры находятся в [`bridge/README.md`](bridge/README.md).

Не включай `ALLOW_DEMO_EVENTS=true` на публичном сервере. В production используй HTTPS/WSS, а токен оставляй только на серверной стороне.

## Размещение

Frontend на Vite можно разместить как статический сайт. Текущий `server/index.js` запускается как отдельный Node.js-сервер, поэтому для него нужен хост, который поддерживает постоянно работающий Node.js-процесс и WebSocket. Vercel уже поддерживает WebSocket в Functions, но этот стартовый сервер пока не адаптирован под формат Vercel Function; при таком варианте дополнительно понадобится общий pub/sub или Redis для синхронизации событий между разными экземплярами Functions. При сборке frontend укажи `VITE_WS_URL=wss://адрес-сервера/ws`.

## Что ещё не подключено

Это рабочая локальная основа игры, но не готовый TikTok-коннектор. Авторизация TikTok, получение реальных чатов/лайков/подарков и автоматическое обнаружение начала эфира должны быть добавлены отдельным адаптером и проверены на реальном тестовом эфире. Событие `live_start` уже поддерживается: когда коннектор его отправит, таблица побед будет автоматически очищена. Ручной сброс уже доступен в панели.

В этой версии статистика хранится в localStorage конкретного браузера. Для общей статистики между устройствами и надёжного хранения истории понадобится база данных на следующем этапе.
